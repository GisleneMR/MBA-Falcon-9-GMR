# MBA-Falcon-9-GMR
This repository contains my applied Data Science Capstone Project.
## Project Objetive
The objective of this project is to analyze Falcon 9 launch data and predict whether the first will land sucessfully. 
## Business Problem
SpaceX can reduce launch costs by recovering and reusing the Falcon 9 first stage. Predicting landing success can help estimate launch costs and support competitive business decisions.
